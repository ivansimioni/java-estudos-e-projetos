## 🚀 Projetos

### 🏦 Sistema Bancário

Projeto desenvolvido para praticar conceitos de **Programação Orientada a Objetos**, simulando operações básicas de uma conta bancária.

**Conceitos praticados:**

- Classes e objetos
- Construtores
- Encapsulamento
- Métodos
- Modificadores de acesso
- Estruturas condicionais

### 📺 Controle Remoto

Projeto desenvolvido para praticar **encapsulamento e interfaces** em Java, simulando o funcionamento de um controle remoto.

**Conceitos praticados:**

- Classes e objetos
- Encapsulamento
- Métodos
- Interfaces
- `private`
- `public`
- `protected`
